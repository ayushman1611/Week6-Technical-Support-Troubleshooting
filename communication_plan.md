# Communication Plan

## Incident Update Template
**Subject:** [Incident ID] – [Service] – [Status]

Hello Team,

We are investigating an issue affecting **[service/function]**.

- Incident: [ID]
- Impact: [who/what is affected]
- Current status: [investigating / workaround available / resolved]
- Action in progress: [plain-language summary]
- Workaround: [if available]
- Next update: [time]

We will provide another update when the situation changes or at the next scheduled update.

## Resolution Template
The issue affecting **[service]** has been resolved.

- Cause: [brief, non-sensitive explanation]
- Action taken: [fix]
- Verification: [tests completed]
- User action: [if any]
- Follow-up: [preventive action]

Thank you.

## Communication Rules
1. Use plain language.
2. Do not expose sensitive technical details unnecessarily.
3. Never request passwords, MFA codes, API secrets or private keys.
4. Give realistic update times.
5. Communicate workarounds as temporary measures.
6. Confirm resolution before closing the incident.
